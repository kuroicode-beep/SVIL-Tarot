# SVIL Tarot PRD (v0.1)

## 목표

저시력 사용자가 타로를 배우고, 스프레드를 익히며, 실전·AI 리딩과 소울카드를 사용할 수 있는 전체화면 웹앱.

## 핵심 기능

1. 타로 배우기 — 단계 레슨 + 퀴즈
2. 스프레드 — 1/3/5카드 소개 + 퀴즈
3. 실전 — 드로우, 나의 해설, Ollama 조언
4. AI 타로 — 질문/카테고리, 전체 리딩
5. 소울카드 — 수비학 1~9 + AI 설명
6. TTS, 저장, 히스토리

## 비기능

- SVIL 고대비 다크 UI, 터치 타겟 ≥50px
- 로컬 LLM (Ollama gemma4:12b), 클라우드 DeepSeek 미사용
- 카드 덱: LoveType low_vision_deck
