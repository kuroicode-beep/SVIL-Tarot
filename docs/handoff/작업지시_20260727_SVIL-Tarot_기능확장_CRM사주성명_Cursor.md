# 업데이트 계획 · 기능 확장 v1.2.0

- 프로젝트: SVIL-Tarot
- 일자: 2026-07-27
- 비교 대상: 도사·신비운(사주/타로/궁합), 운세닷컴·포스텔러(사주·궁합), 작명왕·모두네임·넴유베(성명·작명), MysticLog·AstroCRM·Flowdara(상담자 CRM)

## 시장 앱 대비표 (요지)

| 영역 | 유사 앱 공통 기능 | SVIL-Tarot v1.2 반영 |
|------|-------------------|---------------------|
| 타로 | 스프레드·AI 리딩·저장 | 기존 유지 + 고객 연결 |
| 사주 | 생년월일시·성별·원국 요약·AI 풀이 | 간이 만세력(년주 등)+Ollama 풀이 |
| 궁합 | 두 사람 생년월일·관계유형·점수/해설 | 커플 입력+Ollama 궁합 |
| 성명학 | 이름 획수·오행·발음·풀이 | 한글 성명 분석+Ollama |
| 작명 | 성·성별·사주·후보 이름 추천 | 조건 입력+후보 5안+Ollama |
| CRM | 고객 프로필·생년 정보·세션 기록 | 고객 DB + 상담 이력 |

## 구현 범위

1. IndexedDB v2: `customers`, `consultations` 스토어
2. 고객 목록/상세/등록·수정·삭제, 상담 이력 타임라인
3. 각 서비스 화면에서 고객 선택(또는 신규) 후 결과 자동 상담 기록
4. 기존 타로/실전/AI/소울도 상담 기록에 `serviceType`으로 남길 수 있게 연동(선택 고객 시)
5. 버전 **1.2.0**, 히스토리·홈 메뉴·i18n(ko 우선, en 병행 최소)

## 비범위
